# Caldero

Implementación de una clase `Caldero` en C++ para preparar pociones paso a paso mediante encadenamiento de métodos (*method chaining*).

## Estructura del Proyecto

- `Caldero.h`: Declaración de la clase y prototipos de métodos.
- `Caldero.cpp`: Lógica de preparación y validaciones.
- `main.cpp`: Casos de prueba de preparación exitosa y validaciones.

## Compilación y Ejecución

```bash
g++ -std=c++11 main.cpp Caldero.cpp -o caldero
./caldero
```
